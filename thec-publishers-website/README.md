# Thec Writers & Publishers Website

Public-facing React, TypeScript, Vite, and Tailwind CSS website for Thec Writers & Publishers.

## Run locally

Requirements: Node.js 24 and pnpm 10.

```bash
pnpm install
pnpm dev
```

Open the local URL printed by Vite.

## Production build

```bash
pnpm build
```

The deployable output is generated in `dist/`.

## Before production launch

- Replace the labelled team-image placeholders with approved company photographs.
- Connect the enquiry form to a tested backend or form provider.
- Migrate and verify existing WordPress blog, careers, referral, and WooCommerce data.
- Configure hosting redirects so existing public URLs remain available.
